solcity
Move the cursor in the code: the matching block lights up. Click a block to jump to its line.

Import from GitHub

Paste a link to a public repo, a folder (/tree/…) or a .sol file (/blob/…).

    Import from an address

    Paste a contract address or an explorer link (Etherscan, Basescan, any Blockscout explorer…). Its verified code is loaded, with the implementation if it is a proxy, and the contracts it points to (factory(), token0(), owner()… read from the chain) come along as cities joined by on-chain roads.

    Etherscan key and RPC node (optional)

    Sourcify and Blockscout need no key. An Etherscan API key adds contracts verified only on Etherscan; it is kept in this browser and sent to Etherscan only.
